# Plano design

Plano uses a field-guide palette and a route strip that places the departure and arrival on a common baseline. Native navigation handles back gestures and stack transitions.

| Role | Light | Dark |
| --- | --- | --- |
| Ground | `#F5F7F4` | `#111B19` |
| Surface | `#FFFFFF` | `#182724` |
| Text | `#132522` | `#EDF6F1` |
| Secondary text | `#435C56` | `#B2C8C0` |
| Tint | `#006952` | `#6CE0B8` |
| Divider | `#CFDBD4` | `#3D524B` |

System type handles interface text. Tabular numerals align gate times and flight codes. The spacing scale is 4, 8, 12, 16, 24, and 32 dp. All standalone actions have a 48 dp minimum target.
